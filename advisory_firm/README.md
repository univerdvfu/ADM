# Инвестиционное консультирование на данных Мосбиржи

Учебный прототип фирмы-аналитика. Фирма берёт рыночные данные Московской биржи, считает показатели
(доходность, волатильность, просадка), готовит рекомендации по акциям с учётом риск-профиля клиента
и публикует их только после проверки вторым человеком. Это не биржа и не торговая система.

Стек (из презентации «Биржа (2).pptx»): **PostgreSQL**, **ClickHouse**, **MinIO**, **Airflow**.
Kafka не используется: консультанту нужны дневные бары, а не поток тиков.

## Как развернуть

Нужны: Linux или Ubuntu WSL, Python 3.12, Go (для сборки MinIO), интернет, свободные порты
8123 (ClickHouse), 39010 (MinIO), 8080 (веб-интерфейс Airflow). Sudo не требуется.
Все сервисы слушают только `127.0.0.1`.

```bash
bash deploy/setup.sh                      # установка, около 1 ГБ
bash deploy/start.sh                      # запуск ClickHouse, MinIO, PostgreSQL
bash deploy/airflow.sh test 2026-10-29    # прогон задач DAG по API Мосбиржи
bash deploy/run_tests.sh tests/test_db_complex.py -vv   # 15 тестов БД
bash deploy/demo.sh                       # наглядный отчёт demo/report.html
bash deploy/service.sh                    # сервис просмотра таблиц и тестов, http://127.0.0.1:8765
bash deploy/airflow.sh standalone         # планировщик и веб-интерфейс (не проверялся)
```

Данные и бинарники лежат в `~/advisory-stack` (меняется в `deploy/env.sh`).

На сервере `10.50.16.246` ветка `main` разворачивается автоматически: после push таймер забирает изменения
примерно в течение минуты и перезапускает веб-сервис и Airflow. Подробности и журналы: `docs/DEPLOYMENT_PROXMOX.md`.

## Что проверено, а что нет

- **Проверено.** 15 тестов БД проходят в Ubuntu WSL на настоящих ClickHouse 26.x, PostgreSQL 16,
  MinIO и Airflow 2.10.5. Каждая из пяти задач DAG прогнана вживую: данные забираются из публичного
  API Мосбиржи, сырьё попадает в MinIO, справочники в PostgreSQL, бары в ClickHouse (325 баров,
  5 бумаг, ошибок качества 0), создаётся 10 черновиков рекомендаций. `deploy/start.sh` и
  `deploy/airflow.sh test` запускались из этой папки.
- **Развёрнуто на Proxmox:** контейнер 107, `http://10.50.16.246/`, Airflow `:8080`, PostgreSQL `:5432`, ClickHouse `:8123` (подключение и пароли: `docs/DEPLOYMENT_PROXMOX.md`). Там `setup.sh` прошёл с нуля, все службы подняты, DAG выполнен планировщиком Airflow (два запуска, оба `success`).
- **Не проверено.** Локальный `airflow dags test` в WSL завис; запуск по расписанию в 19:00 МСК дождаться не удалось.
- **Слайды.** Файл прошёл структурную проверку, но визуально не просматривался: в среде не было
  LibreOffice/PowerPoint. Откройте и проверьте, не вылезает ли текст за рамки.

## Ограничения

- Публичный API Мосбиржи отдаёт сделки пустыми, поэтому реальны только дневные бары и справочники.
  Тесты по сделкам используют записи в формате ответа ISS, собранные вручную.
- Дивиденды из API не получены; корпоративные события в тестах заведены вручную.
- Правила рекомендаций учебные (импульс за 20 сессий, фильтр по классу риска, лимит доли позиции).
  Это не инвестиционная методика, и рекомендациями для реальных клиентов считаться не может.
- ClickHouse не проверяет внешние ключи и уникальность: это делает загрузчик.
- Роли реализованы в коде приложения, а не в правах БД.
- Условия лицензии на данные Мосбиржи нужно проверить отдельно.
- Таблицы `signals` и `recommendations` в ClickHouse остались от прежней версии и дублируют журнал
  в PostgreSQL; их стоит удалить.
- Учётные данные MinIO (`testadmin`) тестовые; для чего-либо кроме локальной проверки замените их.
